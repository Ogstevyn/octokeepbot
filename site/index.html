What OctoKeep does

Two jobs, both remembered.

FeatureYou sendOctoKeep doesComes back
Saved postsDefault 2 days A link to a post, video or article Sends a short summary and the actions in it, then asks what you plan to do After the gap you choose, and asks if you did it
TasksUp to 3 questions "Build an app Thursday, remind me" Confirms the date and asks a few short questions about the task At the time you set, with an organised plan
OutcomesLearns from you Done, Snooze or Drop Remembers what you finished and what you skipped Uses it to shape the next reminder

Set up in five minutes

You own your memory. OctoKeep only gets a key you can revoke.

Open the bot
  1. 1

    Create your Walrus Memory account

    Open memory.walrus.xyz, sign in, and finish the account setup.

  2. 2

    Create a key for OctoKeep

    Under Delegate keys, select Add key and name it OctoKeep. A separate key means you can cut OctoKeep off later without touching anything else.

  3. 3

    Copy two values

    From SDK credentials, copy your Account ID and the delegate private key for that key. Treat the private key like a password and do not post it anywhere else.

  4. 4

    Start the bot

    Open @OctoKeep_bot, send this, and choose your timezone so reminders arrive at the right hour.

    /start
  5. 5

    Connect your memory

    Send this, then paste the Account ID and the private key when asked. OctoKeep deletes your message straight away and stores the key encrypted.

    /connect
  6. 6

    Send your first link

    Paste a link to a video, article or post. For Instagram and TikTok, paste the caption as text, since OctoKeep does not scrape those apps.

Your memory, your keys

What is stored, where, and how to switch it off.

QuestionAnswer
Where your memory lives Encrypted on Walrus, in your own Walrus Memory account. It is not tied to OctoKeep, so it goes wherever your account goes.
What OctoKeep stores Your Telegram ID, timezone and reminder schedule, plus your account ID and delegate key, encrypted.
How to cut it offRevocable Delete the OctoKeep key in your Walrus Memory dashboard. OctoKeep can no longer read or write your memory.

npm run dev
import { MemWal } from "@mysten-incubation/memwal"

const memory = MemWal.create({
  key: process.env.MEMWAL_PRIVATE_KEY,
  accountId: process.env.MEMWAL_ACCOUNT_ID,
  serverUrl: process.env.MEMWAL_SERVER_URL,
  namespace: "octokeep",
})

// Save what the user committed to, then wait for the write
const job = await memory.remember("[SAVE] Cloud cert video | book the exam | due in 2 days")
await memory.waitForRememberJob(job.job_id)

// Later, recall it to word the reminder
const { results } = await memory.recall({ query: "what did I plan to do this week" })

Never put a private key in client code or in this site. Keys belong in server environment variables only.
